# Projet Tom Troc

## Pour utiliser ce projet : 

- Commencer par cloner le projet. 
- installez le projet chez vous, dans un dossier exécuté par un serveur local (type MAMP, WAMP, LAMP, etc...)
- Une fois installé chez vous, créez un base de données vide appelée : "tomtroc"
- Importez le fichier _tomtroc.sql_ dans votre base de données.

## Lancez le projet : 

Pour la configuration du projet renomez le fichier _\_config.php_ (dans le dossier _config_) en _config.php_ et éditez-le. 
Ce fichier contient notamment les informations de connexion à la base de données. 

Les comptes utilisateurs présents dans la base de données utilisent tous le mot de passe _password_.

## Problèmes potentiels :

Ce projet a été réalisé avec PHP 8.3.16 Bien que d'autres versions de PHP puissent fonctionner, il n'est pas garanti que le projet fonctionne avec des versions antérieures.
